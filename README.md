# paper

Paper — статический журнал статей в Bento / editorial стиле.

## Возможности
- Адаптивная сетка карточек, темы, теги и поиск.
- Просмотр полных материалов и ссылка на первоисточник.
- Добавление, редактирование и удаление статей через встроенный редактор.
- Импорт и экспорт коллекции в JSON.
- Восемь ссылок JoyReactor заведены как черновики до проверки оригинального текста и комментариев.

## Запуск
Откройте index.html или запустите `python3 -m http.server 8000`.

## Хранение
Редактор сохраняет изменения в localStorage текущего браузера. Экспортируйте JSON для резервной копии и переноса. Чтобы изменения стали доступны всем посетителям, обновите данные в репозитории.

## GitHub Pages
